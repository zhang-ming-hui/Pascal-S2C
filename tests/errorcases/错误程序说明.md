# Pascal 编译典型错误示例

本文档用于展示在 Pascal 编译器各阶段可检测到的典型错误，分别为词法分析、语法分析和语义分析阶段。每个示例均为独立程序，植入单一类型的错误，便于测试与教学。

# 语法分析阶段错误示例

以下程序均存在纯粹的语法结构错误，可在语法分析阶段被检测，不涉及词法错误（如非法字符）或语义错误（如类型不匹配、变量未声明）。所有程序采用标准 Pascal 语法，关键字大写，并可按给出的名字保存为 `.pas` 文件。

---

## 1. MissingSemicolon.pas – 语句间缺少分号

```pascal
program MissingSemicolon(input, output);
var
   x, y : integer;
begin
   x := 1
   y := 2
end.
```

**错误说明：**  
赋值语句 `x := 1` 后缺少语句分隔符 `;`，语法分析器期望在此处遇到 `;` 或 `end`，却读到了标识符 `y`，导致结构错误。

---

## 2. SemicolonBeforeElse.pas – else 前的非法分号

```pascal
program SemicolonBeforeElse(input, output);
var
   a : integer;
begin
   a := 5;
   if a > 0 then
      writeln('positive');
   else
      writeln('non-positive')
end.
```

**错误说明：**  
Pascal 的分号是语句分隔符。`if` 语句的 `then` 分支以分号结束时，该 `if` 语句被视为已完整，随后的 `else` 找不到匹配的 `if`，因此产生语法结构错误。

---

## 3. UnbalancedParentheses.pas – 括号不匹配

```pascal
program UnbalancedParentheses(output);
begin
   writeln( (1 + 2 * 3 )
end.
```

**错误说明：**  
表达式中有两个 `(`，但只有一个 `)`，导致右括号缺失。语法分析器在到达语句末尾时仍未看到闭合括号，报告括号不匹配。

---

## 4. MissingFinalDot.pas – 缺少程序结束句点

```pascal
program MissingFinalDot(output);
begin
   writeln('Hello')
end
```

**错误说明：**  
Pascal 程序必须以 `end.` 结束（注意末尾的句点）。此处仅写了 `end`，缺少 `.`，使得分析器无法将整个程序规约为完整单元。

---

## 5. IncompleteArrayDeclaration.pas – 数组类型声明不完整

```pascal
program IncompleteArrayDeclaration(output);
type
   arr = array [1..10] of ;
begin
end.
```

**错误说明：**  
数组声明中关键字 `of` 之后必须紧跟元素类型标识符，但此处直接出现分号，导致语法分析器期望类型名而得到非法分隔符。

---

## 6. ForLoopMissingDo.pas – for 循环缺少 do

```pascal
program ForLoopMissingDo(output);
var
   i : integer;
begin
   for i := 1 to 10
      writeln(i)
end.
```

**错误说明：**  
`for` 语句的结构要求：

```pascal
for 变量 := 初值 to/downto 终值 do 语句
```

此处缺少 `do`，使得 `writeln(i)` 无法被正确关联为循环体。

---

## 7. CaseMissingEnd.pas – case 语句缺少 end

```pascal
program CaseMissingEnd(output);
var
   n : integer;
begin
   n := 1;
   case n of
     1 : writeln('one');
     2 : writeln('two')
   { 缺少 end 结束 case }
end.
```

**错误说明：**  
`case` 语句的各个分支后需要 `end` 来标记结束。缺失后，分析器无法与外围结构正确连接。

---

## 8. IllegalLeftValue.pas – 非法赋值左值

```pascal
program IllegalLeftValue(output);
begin
   3 := 5
end.
```

**错误说明：**  
赋值语句左侧必须是变量（合法的左值），字面常量 `3` 不符合文法对左值的要求，语法分析器可直接拒绝。

---

## 9. DuplicateCommaInParameterList.pas – 参数表连续逗号

```pascal
program DuplicateComma(output);
procedure p(a ,, b : integer);
begin
   writeln(a,b)
end;
begin
   p(1,2)
end.
```

**错误说明：**  
在过程 `p` 的参数列表中出现了连续两个逗号 `,,`，语法分析器在预期参数名时读到一个逗号，导致结构错误。

---

## 10. MissingThenInIfStatement.pas – if 语句缺少 then

```pascal
program MissingThen(output);
var
   x : integer;
begin
   x := 10;
   if x > 0
      writeln('positive')
end.
```

**错误说明：**  
`if` 语句的条件表达式后必须跟关键字 `then`，此处缺失，分析器不能将后续语句正确归入 `if` 结构。

---

## 11. WrongSemicolonAfterBegin.pas – begin 后的非法分号

```pascal
program WrongSemicolonAfterBegin(output);
begin;
   writeln('oops')
end.
```

**错误说明：**  
`begin` 标志复合语句的开始，其后不应直接跟分号（分号是语句分隔符，应出现在第一条语句之后）。此处的分号导致空语句或结构异常，语法分析器会报错误。
